# Architecture Decisions

Each ADR separates **accepted decisions** from **unverified assumptions** (expected behavior not yet tested) and **open questions**. When implementation contradicts an assumption, update the ADR in the same change. To reverse an accepted decision, add a dated "Revised" entry explaining why.
